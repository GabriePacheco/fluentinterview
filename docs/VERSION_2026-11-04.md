# Versión guardada antes de revisar la personalización

El propietario solicita guardar el estado actual y subirlo a un repositorio remoto. Esta instrucción reemplaza la restricción previa de Git exclusivamente local; el destino debe corresponder a este proyecto.

Incluye acceso con Google, persistencia, onboarding con nombre y sugerencias profesionales, diagnóstico inicial y generación gratuita de ruta, recuperación de resultados, planes Esencial/Pro/Intensivo y control de minutos de voz en servidor. El diagnóstico inicial solicita automáticamente la calificación y muestra un modal cuando la nota y la ruta están listas.

Planes configurados en Lemon Squeezy TEST: Esencial US$9,90 / 60 minutos; Pro US$19,90 / 150 minutos; Intensivo US$34,90 / 300 minutos. No son cobros comerciales reales. Los minutos corresponden a voz; el canal escrito conserva un cupo independiente. El contador actual usa mes calendario UTC.

Limitación reconocida: las rutas, ejemplos y conversaciones observados por el propietario son demasiado similares entre perfiles. La adaptación por nivel y puesto no satisface todavía la personalización esperada. Se conserva este estado como referencia previa a corregir ese problema; este commit no certifica que esté solucionado.

Verificaciones realizadas durante esta entrega: 35 pruebas focalizadas de comercio, sesiones, recuperación y rutas; tres pruebas de onboarding; compilación del bundle y comprobaciones de sintaxis. Sin llamadas pagadas como parte del guardado.
